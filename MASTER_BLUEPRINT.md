# Jarvis AI Agent — Master Blueprint

## 1. Project Purpose
This is a learning demo for building a safe, modular Jarvis-style AI assistant on Windows.

## 2. Project Owner
The user is the Product Owner and final decision-maker.

## 3. Learning Goals
- Learn Git and GitHub using GitHub Desktop.
- Maintain project documentation.
- Learn how to give AI coding agents scoped tasks.
- Review changes before accepting them.
- Test features and track progress.

## 4. Planned Features
- Text chat interface.
- Voice input and output.
- AI assistant with local/cloud model options.
- File and folder assistance.
- Browser research assistance.
- Coding and project assistance.
- Long-term memory with privacy controls.
- Optional image and video creation integrations.
- Future PC automation with explicit user approval.

## 5. Safety Rules
- Ask for approval before consequential actions.
- Never delete or overwrite user files without explicit approval.
- Never expose passwords, API keys, or other secrets.
- Do not run commands or install software without the required approval.
- Show the proposed changes before accepting significant modifications.
- Do not claim tests passed unless they were actually run.

## 6. Development Rules
- Inspect the existing project before changing it.
- Implement only the approved task.
- Avoid unrelated changes.
- Update relevant documentation when requirements change.
- Test changes and report failures honestly.
- Keep changes small enough to review.
